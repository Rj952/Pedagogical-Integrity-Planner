# The Pedagogical Integrity Planner

A planning instrument for **pedagogical sovereignty** in AI-mediated learning. It walks educators through seven decisions that distinguish transformative AI use from behaviourist drill in disguise — grounded in the **CARE**, **CRAFT**, and **ACRE** frameworks and the **Pedagogical-Centred AI (PCAI)** commitment to splitting human control between teacher and learner.

**Developed by Rohan Jowallah.**

## What it does

Seven steps:

1. **Setup** — Name the lesson, outcome, and AI tool.
2. **Anchor** — Choose the pedagogical theory the lesson sits inside.
3. **Control** — Set the PCAI split between teacher control and learner control.
4. **CRAFT** — Architect the AI prompt: Context · Role · Action · Format · Threshold.
5. **CARE** — Sequence learner engagement: Consider · Analyse · Reflect · Evaluate.
6. **ACRE** — Quality-check the AI output: Accuracy · Completeness · Relevance · Equity.
7. **Plan** — Receive a 0–100 pedagogical-integrity score, flagged risks, and a copyable lesson plan.

## Design

- **Caribbean palette** — deep sea blue, palm green, sunshine, Trinidad coral
- **WCAG AA+ contrast** — body text reaches 19:1, all interactive elements clear focus rings
- **Keyboard-first** — skip-link, semantic landmarks, ARIA, prefers-reduced-motion and prefers-contrast respected
- **Single file** — pure HTML + React via Babel-standalone CDN. No build step, no install.

## Deploy

Static site — drop `index.html` on any static host. Live deployment connected to this repo via Vercel.
